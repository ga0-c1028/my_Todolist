001.
너는 최고의 비즈니스 도메인 전문가야. "my_Todolist"라는 이름의 할 일 관리 애플리케이션을 개발하려고 해. 다음 내용을 바탕으로 적절한 서브에이전트를 활용해 도메인 정의서 초안을 작성해줘.

# 문제 정의 :
- 인증된 사용자 개인별로 할일을 관리할 수 있는 앱이 없다.
- 할일 관리앱에 시작일과 종료일을 다룰 수 있는 기능이 필요하다.

# TodoList 앱의 주요 기능 :
- 회원가입 후 로그인(인증) 후 이 앱을 사용할 수 있다.
- 카테고리 별로 할일을 등록하며, 카테고리를 지정하지 않을 경우 '기본' 카테고리를 적용한 것으로 간주한다.
- 로그인한 사용자는 자신의 정보를 수정할 수 있어야 한다.
- 할일을 등록할 때 시작일자, 종료일자를 캘린더로 선택, 지정할 수 있어야 한다.
- 할일 목록 조회화면에서 다음 항목을 중심으로 필터링 할 수 있어야 한다.
  * 카테고리별 필터링
  * 시작하지 않은 할일 목록만으로 필터링
  * 진행중인 할일 목록 만으로 필터링
  * 완료된 할일 목록 필터링
  * 종료일자가 지났지만 완료되지 않은 할일 목록 필터링
- 할일은 인증된 사용자가 삭제할 수 있다.
- 할일은 인증된 사용자가 편집화면으로 수정할 수 있다.

# 기술 제약사항

   * 프론트엔드: React 19 + Typescript + Zustand(전역 상태관리) + Tanstack Query(백엔드와의 상태 동기화)

   * 데이터베이스: postgresql 17 사용
