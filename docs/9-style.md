## 1. 개요 및 목적

본 문서는 `docs/4-wireframe.md`(W-01~W-06)의 레이아웃을 실제 화면으로 구현할 때 따를 시각 디자인 규칙(색상·타이포그래피·컴포넌트 스타일)을 정의한다. 3개의 레퍼런스 이미지를 근거로 구성했으며, 각 레퍼런스가 담당하는 역할은 다음과 같다.

| 레퍼런스 | 역할 | 가져오는 요소 |
|---|---|---|
| 레퍼런스 1(GRASS 포스터) | 컬러 팔레트 | 머스터드 옐로 배경 + 블랙 + 핫핑크 그라데이션 포인트 |
| 레퍼런스 3(OK DRUGS 웹사이트) | 전체 레이아웃/구조 | 넓은 여백, 굵은 산세리프 타이포, 비대칭 이미지 블록, 얇은 화살표 아이콘, 모노스페이스 하단 바 |
| 레퍼런스 2(손그림 캘린더) | 캘린더 컴포넌트 | 할일 등록/수정(W-04)의 날짜 선택 UI 전용 스타일 |

## 2. 컬러 팔레트

레퍼런스 1의 고채도 머스터드 옐로 배경에 블랙 텍스트, 핫핑크 포인트 컬러를 조합한 팔레트를 기본으로 한다. 배경이 이미 강한 컬러이므로 텍스트·아이콘은 흑백 대비로 가독성을 확보하고, 핑크는 인터랙션 포인트(선택·강조·완료 표시)에만 제한적으로 사용한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-primary` (머스터드) | `#F2B705` | 주요 배경, 헤더/히어로 영역, Primary 버튼 배경 |
| `--color-primary-dark` | `#D9A200` | Primary 버튼 hover/active |
| `--color-accent` (핫핑크) | `#F03A9B` | 강조 포인트: 진행중 상태 뱃지, 링크 hover, 포커스 링, 활성 탭 |
| `--color-accent-gradient` | `linear-gradient(180deg, #FFFFFF 0%, #F9C4E0 40%, #F03A9B 100%)` | 레퍼런스 1의 잎사귀 그라데이션 — 빈 상태(empty state) 일러스트, 로딩 스피너 등 장식 요소에 한정 사용 |
| `--color-ink` (블랙) | `#111111` | 본문 텍스트, 헤딩, 아이콘 |
| `--color-surface` (오프화이트) | `#FAF6EE` | 카드/모달/입력 필드 배경, 내비게이션 바 배경(레퍼런스 3의 크림색 헤더) |
| `--color-border` | `#111111` | 카드·입력 필드 테두리(두꺼운 블랙 보더, 레퍼런스 2 참고) |
| `--color-danger` | `#E5484D` | 기한초과 상태, 삭제 버튼, 필수 입력 에러 |
| `--color-info` | `#2E6ADE` | 완료 상태 뱃지(레퍼런스 2의 SAT 파란색을 차용해 "완료"에 배정, 위험색과 구분) |
| `--color-muted` | `#6B6558` | 보조 텍스트, placeholder, 비활성 상태 |

- 배경은 기본적으로 `--color-primary`(머스터드)를 화면 전반 또는 히어로/헤더 영역에 크게 쓰고, 콘텐츠 카드(할일 목록의 개별 항목, 폼 등)는 `--color-surface` 위에 블랙 보더로 올린다 — 레퍼런스 3의 "오렌지 배경 위 흰 카드" 구조를 그대로 따른다.
- 핑크(`--color-accent`)는 팔레트 전체에서 가장 채도가 높으므로 화면당 1~2곳(활성 탭, 주요 CTA hover, 진행중 상태 뱃지)으로 제한한다. 남용하면 레퍼런스 1의 포스터 같은 강한 인상이 아니라 산만한 화면이 된다.

## 3. 타이포그래피

레퍼런스 3처럼 두꺼운 산세리프 헤드라인 + 일반 굵기 본문의 대비를 기본 원칙으로 한다.

| 용도 | 폰트 | 웨이트/크기 | 비고 |
|---|---|---|---|
| 헤드라인(H1, 히어로 문구, "할일 등록" 등 화면 타이틀) | Pretendard 또는 Archivo Black 대체 시스템 산세리프 | 800~900, 32~48px, 자간 -2%, 대문자/한글 모두 굵게 | 레퍼런스 1·3 공통의 초굵은 헤드라인 |
| 섹션 타이틀(H2, 카드 제목) | Pretendard | 700, 20~24px | |
| 본문/라벨 | Pretendard | 400~500, 14~16px | |
| 메타 정보(날짜, 상태 라벨, 타임스탬프) | Pretendard 또는 모노스페이스(JetBrains Mono) | 500, 11~12px, 자간 +4%, 대문자 표기 | 레퍼런스 3 하단 "SOMETHING AMAZING IS ABOUT TO HAPPEN" 바의 스몰캡스 모노 스타일 — 상태 뱃지·필터 칩에 적용 |
| 캘린더 월 타이틀(W-04 전용) | 손글씨 느낌 폰트(예: Gaegu, Nanum Pen Script) | 400, 28~32px | 레퍼런스 2의 손그림 "January" 제목 |

- 한글 프로젝트이므로 영문 전용 폰트(Archivo Black 등)는 실제 서비스에 넣지 않고, Pretendard의 최고 굵기(Black/ExtraBold)로 같은 인상을 낸다.
- 버튼/CTA 텍스트는 항상 굵게(700 이상) + 대문자 또는 강조 색상으로, 레퍼런스 3의 "SHOP NOW"처럼 화면에서 가장 시선이 먼저 가는 요소로 만든다.

## 4. 레이아웃 및 컴포넌트 원칙

레퍼런스 3의 구조를 기본 골격으로 삼는다.

- **내비게이션**: 상단 고정 바, 배경은 `--color-surface`(크림), 로고는 원형 배지, 메뉴 항목은 기본 블랙 텍스트에 현재 화면만 `--color-accent`로 강조(레퍼런스 3의 "Home" 링크 처리와 동일). `docs/4-wireframe.md` 3.1절의 공통 내비게이션에 그대로 적용한다.
- **여백**: 섹션 간 여백을 넉넉하게(최소 32px, 데스크톱 히어로급 섹션은 64px 이상) 두어 레퍼런스 3의 시원한 공간감을 재현한다. 여백을 줄여서 정보 밀도를 높이려는 시도는 지양한다.
- **카드**: 블랙 2px 실선 보더 + 4~8px 라운드(레퍼런스 2의 손그림 박스처럼 각지지 않게) + 은은한 그림자 없음(플랫). 카드 배경은 `--color-surface`, hover 시 보더를 `--color-accent`로 전환.
- **버튼**:
  - Primary: 배경 `--color-ink`(블랙), 텍스트 흰색, hover 시 `--color-accent`로 배경 전환.
  - Secondary/텍스트 버튼: 배경 없음, 블랙 텍스트 + 밑줄 또는 화살표 아이콘(`→`) 조합 — 레퍼런스 3의 "Get your feel good fix... →" 스타일.
- **아이콘**: 얇은 선(1.5px stroke) 아웃라인 아이콘을 기본으로 하고, 별표(✳) 같은 장식 아이콘은 빈 상태·완료 축하 등 저빈도 이벤트에만 사용한다.
- **상태 뱃지**(할일 상태: 시작 전/진행중/완료/기한초과): 스몰캡스 모노스페이스 텍스트 + pill 형태 배경.
  - 시작 전: `--color-muted` 배경, 흰 텍스트
  - 진행중: `--color-accent`(핑크) 배경, 흰 텍스트
  - 완료: `--color-info`(블루) 배경, 흰 텍스트, 텍스트에 취소선 없이 체크 아이콘 병기
  - 기한초과: `--color-danger` 배경, 흰 텍스트
- **하단 유틸리티 바**(선택): 로그인 후 화면 최하단에 블랙 배경 + 흰색 스몰캡스 텍스트로 현재 필터·정렬 상태 등을 표시하고 싶다면 레퍼런스 3의 티커 바 스타일을 재사용할 수 있다(필수 아님).

## 5. 캘린더 컴포넌트(W-04 전용)

할일 등록/수정 화면의 시작일자·종료일자 선택 UI는 레퍼런스 2의 손그림 캘린더 톤을 따른다. 나머지 화면의 각진 시스템 폰트/컬러와 의도적으로 다른 "손으로 그린" 톤을 줘서 날짜를 고르는 행위 자체를 가볍고 친근하게 만든다.

- 월 타이틀: 손글씨 폰트(3절 참고)로 크게 표시.
- 요일 헤더: 필 형태 배지, 일요일은 `--color-danger` 배경, 토요일은 `--color-info` 배경, 나머지 평일은 `--color-ink` 배경 + 흰 텍스트(레퍼런스 2와 동일한 색 배정).
- 날짜 셀: 흰 배경 + 블랙 손그림풍 둥근 사각 보더(각 셀이 미세하게 삐뚤빼뚤해 보이도록 `border-radius`를 8~12px로, 완벽한 정사각형 대신 살짝 비대칭 느낌을 주는 정도로만 처리 — 과도한 손그림 SVG 보더 이미지까지는 만들지 않는다).
- 날짜 숫자 색: 평일은 블랙, 일요일·해당 월 밖 날짜는 `--color-danger`/`--color-muted` 톤, 토요일은 `--color-info` 톤.
- 선택된 시작일자~종료일자 범위: `--color-accent`(핑크) 배경으로 범위 전체를 채워 시작일~종료일 구간이 한눈에 보이게 한다(BR-6: 종료일자는 시작일자 이상).
- 오늘 날짜: 블랙 2px 보더로만 별도 표시(배경색 채우지 않음)해 선택 상태와 혼동되지 않게 한다.

## 7. 비고

- `docs/2-prd.md`에 따라 접근성 심화 대응(WCAG 준수 등)은 범위 밖이나, 배경(머스터드)과 텍스트(블랙)의 명도 대비는 충분히 높게 유지되므로 최소한의 가독성은 확보된다. 핑크 위에 흰 텍스트를 올리는 조합만은 대비가 약할 수 있어 피하고, 핑크는 항상 배경으로만 쓰고 텍스트는 블랙 또는 흰색 중 대비가 큰 쪽을 선택한다.
- 본 문서는 프론트엔드 구현(FE Task) 착수 전 참조용이며, 실제 컴포넌트 라이브러리 선정 시 색상 토큰 이름(`--color-*`)을 그대로 CSS 변수 또는 Tailwind 커스텀 테마 키로 사용할 수 있다.
